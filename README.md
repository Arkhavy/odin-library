# Javascript Course : Library

As asked in the introduction of [the project](https://www.theodinproject.com/lessons/node-path-javascript-library), the library project is an extension of the [object constructor lesson](https://www.theodinproject.com/lessons/node-path-javascript-object-constructors) that happened right before this project. The goal is to practice Javascript and mostly objects creation, instanciation, inheritance, prototypes, methods, all with a little bit of UI on top.
As always, I'm going to go for the bare minimum on the project, unless I find something interesting enough to be pushed from my point of view to practice a bit more.
